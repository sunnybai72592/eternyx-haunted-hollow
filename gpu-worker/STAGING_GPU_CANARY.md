# First REAL ETERNYX GPU Video — approval-gated staging canary

**Status: source code only. Not executed. No GPU has been rented, no weights have
been downloaded, and no AI video has been generated by this test.**

This is a controlled **one-request manual canary** for our existing local Wan
2.1 text-to-video runner. It is not wired to paid customer traffic or GitHub
Actions. The dedicated GitHub CI invokes only its offline tests.

## Required before testing on a GPU
- Operator must independently approve the provider, a small account-level
  spending cap, and the hardware lease. This script **cannot limit rental
  billing after it exits**: configure GPU provider auto-stop, usage quotas
  and forced termination externally. Dedicated allocated GPUs can keep
  charging while idle.
- Operator must separately provision the GPU, Python/CUDA environment and
  FFmpeg/`ffprobe`. The script has no cloud API and cannot rent anything.
- Review commercial model license and security; **pin a fixed 40-character
  repository revision** and verify a complete manifest of SHA-256 hashes for
  *every* local model file. No model is downloaded by this script.
- Provide a private folder with mode 0700 for new output artifacts. Running
  inference can use significant CPU, disk, GPU RAM and bandwidth.

### Model integrity manifest
A reviewed, operator-maintained JSON file at an absolute path:
```json
{
  "modelId": "Wan-AI/Wan2.1-T2V-1.3B-Diffusers",
  "revision": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
  "files": {
    "model_index.json": "64-lowercase-hex-sha256"
  }
}
```
The above is **format illustration only**, not an authentic model snapshot.
Do NOT copy the illustration revision or digest into a real deployment.
The CLI rejects missing, modified, symlinked or unlisted files. The manifest
must be maintained outside the model directory and vetted against trusted
upstream immutable model provenance. Do not accept user-supplied model URLs.

### Approved staging command (illustration; do not run until funding approved)
```sh
export ETERNYX_GPU_STAGING_ENV=isolated_staging
python3 gpu-worker/staging_gpu_canary.py \
  --approval I_APPROVE_ONE_STAGING_WAN_GPU_TEST \
  --hourly-cents 150 \
  --allowance-cents 100 \
  --max-seconds 300 \
  --model-dir /absolute/reviewed/model \
  --manifest /absolute/reviewed/model-hashes.json \
  --private-dir /absolute/restricted/videos
```
The `150` example is **hypothetical**; verify your provider's actual billing,
including idle, startup, storage and per-minute minimums. The allowance is a
local check based on declared hourly rate, a runtime timeout and 20% buffer,
**not** enforcement of the provider's overall account charges. The test
renders one 1-second 16:9 clip with a fixed, non-customer test prompt.

### Evidence
If inference actually finishes, the script checks the MP4 size and calls
`ffprobe` to confirm a video stream with positive frame dimensions. It
writes a sanitized JSON record containing model ID/revision, GPU model,
elapsed wall time, declared test budget ceiling, generated file bytes,
video width and height. It **does not expose** the actual media, customer
prompts, GPU provider credentials or private file paths.

Before enabling the UI, also run real video playback/decoding checks, verify
private Supabase output materialization and user ownership, accepted safety
moderation, real credit settlement/reconciliation, authenticated requests,
rate limits, and an independently verified maximum spend at the GPU provider.
