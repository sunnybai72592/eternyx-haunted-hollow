## Wave 24 candidate
Atomic global reservation v2 adds fixed UTC minute/day caps (60 requests/minute, 1024/day, 1 GiB/day) to Wave 23 per-owner caps. A global denial rolls back the owner reservation and receipt in a subtransaction. The handler requires the v2 RPC and fails closed if unavailable. This is aggregate protection for authorized operations, not IP throttling or an upstream DDoS defense; global denial can affect innocent accounts. Keep v1 RPC server-only for the wrapper; no app role may call either. New SQL is outside canonical migrations and has not been applied. Offline CI includes actual disposable PG17 quota tests and mocked handler regressions.

Read-only operator reconciliation script returns aggregate counts for missing objects, unsealed records, unregistered objects and seals, and charged usage. It does not certify content bytes, delete evidence, backfill digests or expose identifiers. Run only in the intended project and retain only aggregate reports. Quota/receipt retention and orphan review need explicit policy; do not run automated destructive cleanup. Do not claim existing unsealed evidence is verified.
