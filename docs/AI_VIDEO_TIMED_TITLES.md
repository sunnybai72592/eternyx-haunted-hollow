# Timed cinematic titles

Add up to three chronological, non-overlapping overlays: centered introduction or closing text, upper-left label, lower-third title. Each supports white/gold/cyan and static or fade animation. Timing uses 250 ms steps (exact native 16/24 FPS frames), minimum 500 ms. Text is 1–40 printable ASCII characters. A local FFmpeg build with drawtext and working Sans font is required; fonts vary by operating system. The renderer writes text into fixed temporary local files, disables drawtext expansion, and deletes temporary text files before publishing. User text never enters a filter expression. The renderer burns titles into the video after scene transitions, with unchanged cuts, audio and captions. The storyboard, editable draft and receipt record exact text and timing. Tests verify actual decoded glyph pixels, fade timing, blank intervals and all three delivery variants. No upload or AI service. Original source preview remains unchanged; custom fonts, non-ASCII and per-character animation are not supported.
