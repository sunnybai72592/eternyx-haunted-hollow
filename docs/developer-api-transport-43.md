# Developer Studio 4.3 — interactive API request transport
The main API Workbench now shares a bounded, browser-direct transport. It refuses redirects, omits ambient cookies and referrer URLs, and keeps caller-supplied headers explicit. Write methods prompt for confirmation against the target origin. Cancel aborts the active request, including body reads; a late response cannot become a successful result. A 30-second overall deadline remains in place. Response-header latency and total duration are measured independently. The raw body is capped at 1 MB, and JSON pretty-printing cannot exceed that byte budget. The UI compares request and environment snapshots in memory: edits invalidate current assertions and disable copying stale cURL or response body. Editing assertions evaluates the current response without sending another request. Raw request/response content is not persisted by these features. Exported cURL can contain manually supplied credentials; treat it as sensitive. This remains CORS-limited and is not authenticated staging, RLS, or production certification. Also repairs structured JSON media-type matching in the linked project suite. Browser acceptance uses only the authorized local loopback endpoint; hosted staging still does not send API suite or composer requests.
