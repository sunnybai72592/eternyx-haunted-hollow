# AI Arsenal Phase 23 — evidence assurance

After Phase 22 structural citation review, each claim can be reviewed locally by a person. Quote candidates are exact substrings from cited passages, ranked by shared normalized words. They are not proof of semantic support. The reviewer may choose a candidate or paste an exact 8–240 character excerpt. Only a unique occurrence in the cited passage is accepted; offsets refer to the decoded UTF-16 source. Multiline text may need a single-line selection because browser textareas normalize line endings. The reviewer explicitly chooses supported, partial, unsupported or conflicting. A recorded assessment requires an exact excerpt and a chosen verdict. Changing the draft invalidates its recorded verdict. Changing the evidence or submitting a fresh AI request clears the entire review.

Advisory lexical diagnostics flag absent claim words, literal number/unit pairs missing from cited text and differing sets of literal values sharing a unit across cited passages. These checks do not normalize units, resolve dates, understand negation or context, or prove a contradiction. Same-unit quantities may describe different objects. Only a limited set of unit spellings is recognized. All assessments remain manual; no auto-approved claim or artificial confidence percentage. The counts-only clipboard report excludes source labels, names, values, claims and quotes. No new network requests, storage, dependencies, backend changes or AI costs beyond the existing optional Phase 22 synthesis request.

## Acceptance
Run focused Phase 16–23 regressions, full build and full suite. In browser use synthetic source text, obtain a structurally valid response with known matching and differing numeric values, select an exact excerpt, explicitly choose each verdict, verify changed excerpts invalidate assessments, reject ambiguous and fabricated quotes, check counts-only report, confirm new requests and source edits clear all review state. Check keyboard/mobile and insufficient/invalid model output. Source tests are not proof of live AI quality, factual accuracy or browser acceptance.
