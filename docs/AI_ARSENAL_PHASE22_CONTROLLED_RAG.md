# AI Arsenal Phase 22 — controlled lexical RAG synthesis

Phase 21 still prepares and copies local evidence without network calls. The new optional path separately prepares a structured synthesis request from explicitly selected, locally reverified passages. It uses the existing ai.documents.analyze studio bridge, ai.chat entitlement, configured external AI provider and saved chat history. There is no new provider or runtime dependency, but an actual submission may consume credits and incur provider costs. The exact wrapped message is previewed and validated against the 4,000-character limit; nothing is silently truncated. Local privacy scanning of question, source names and decoded passage text is advisory and never auto-redacts. If preparation fails, no request is sent.

Submission requires affirmative review, a separate confirmation, a fresh packet and exact message comparison. Consent is consumed on submission. Changing sources, search options, selection or question invalidates the local draft and response. A sent request cannot be cancelled or refunded by invalidating its UI. No automatic retry.

The response parser accepts a bounded JSON object (or one JSON code fence) with answered/insufficient status, claims and uncertainty. Every claim requires distinct allowed evidence labels. Unknown/missing labels, unexpected fields, invalid shapes and oversized responses are rejected. Valid references show the exact reviewed passage and location, with used/unused counts. Insufficient responses require uncertainty. Rejected responses are labeled raw, unvalidated output. Structural citation validation is NOT semantic entailment, factual verification, prompt-injection immunity, or proof that the model used the evidence. Claims remain untrusted until reviewed. No vector embeddings, new backend changes or model training.
