# Three-track offline mix

Music, narration and sound effects are separate verified local recordings. Each track has its own gain, source trim, entrance, duration, fades and loop toggle. All selected tracks are padded to the same exact sample duration and mixed with equal fixed headroom (1/N per track) so silent intervals do not pump gain. A sole legacy soundtrack keeps its old path. Narration and effects default to non-looping in the editor; specify a duration that fits the recording. Drafts save only metadata and reopen after all selected files pass SHA-256. The portable launcher validates all private media, and the finished receipt records each role. Source-video audio is still removed; original previews are not a live mixed audition. The three-track integration test checks distinct frequencies, entrances, overlaps, exits and final silence in actual decoded MP4 and WebM. No GPU or external AI.
