# Workspace Phase 44 — Team project command center

Eleven actionable counts are derived from the complete current verified team snapshot, before task filters. Each nonempty count opens the existing authorized task list with exact matching filters. Current completion progress is a count, not historical performance.

The attention queue selects outstanding tasks with overdue/today/urgent/assignment-gap reasons, ranks by deadline category then priority/date/ID, and previews at most eight rows with the full matching count. Personal and unassigned queue modes are local views; unknown assignee identities are not surfaced. Opening a task uses the existing scoped discussion with focus and resets conflicting filters. Account/team changes reset queue mode and pending focus.

No schema changes, new permissions, fabricated metrics, paid resources or external integrations. Six regression groups and focused CI coverage. Real authenticated browser and staging tests remain required.
