# AI Arsenal Phase 18 — version comparison and local recovery receipts

This extends Phase 17's verified plaintext/encrypted backup recovery. Select one current source and one verified backup source explicitly. The comparison reports exact decoded text equality, metadata and ID equality, character counts, and deterministic whitespace-sensitive LCS line differences (CRLF/CR normalized to LF only for line comparison). Same ID or name does not prove source lineage. Reordered lines can appear as deletions and insertions. Inputs over 1,200 lines return exact summary but no partial diff. The screen shows at most 20 changed lines and 240 UTF-16 characters per line, with explicit omitted-row/truncation indicators. This local preview can contain sensitive text; do not share the screen indiscriminately. Selection/backup/workspace invalidation discards the preview.

Both confirmed selective recovery and full replacement now produce a counts-only receipt derived from the applied plan/review, including before/after file and character counts, new sources, copies, removals, changed text, metadata-only changes, changed settings count and backup format. The latest receipt stays in component memory and can be copied or cleared; clearing the workspace also clears it. It is historical, not a live workspace inventory. It is not a durable, signed, tamper-proof audit trail, nor does it prove authorship. No filenames, source text, identifiers, digests, query values or passphrases appear in the receipt. No backend, AI, upload or additional runtime dependency.
