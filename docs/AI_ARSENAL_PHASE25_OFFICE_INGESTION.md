# AI Arsenal Phase 25 — local Office ingestion

This adds real, restricted OOXML extraction in the browser. DOCX main-body text, including paragraphs in tables, is extracted in XML order; formatting, page layout, comments, headers, footers, footnotes, embedded files and images are not extracted. XLSX reads workbook relationships, shared strings and inline cells, emits worksheet names and cell references, includes hidden sheets with a warning, and marks formula values as cached or missing. Formulas are never executed, external URLs are not fetched, and number/date styles are not interpreted. Legacy DOC/XLS, encrypted Office files, macro-enabled formats, strict/nonstandard OOXML variants and scanned images are not supported. This is text extraction, not document rendering or lossless round-trip.

The restricted ZIP reader limits input to 8 MiB, 512 entries, 4 MiB per declared part and 32 MiB total declared expansion. It rejects traversal paths, duplicate names, inconsistent headers, overlapping compressed ranges and CRC/size mismatches, and uses streaming output limits for deflated parts. DTD/entity declarations and recognized macro/ActiveX parts are rejected; XML is parsed as data, never rendered as markup. Only known document/worksheet parts are read. Browser-native DOMParser and deflate-raw DecompressionStream are required for compressed archives; unsupported browsers fail closed. These limits are not a formal security audit or a guarantee against all malicious archives. Extraction is bounded but currently runs on the main browser thread; discard suppresses late results rather than forcibly aborting decompression.

Explicit section selection adds TXT representations to the existing corpus subject to its eight-source and character limits. The preview is bounded, but the complete extracted section is imported. Original binary bytes and formatting are not retained in the local corpus. Existing index/search/RAG/backup flows reuse the derived text, filenames and worksheet cell labels; citations are to extracted text, not physical Word pages. No new runtime package, server, AI call or upload. The focused fixture tests use the existing lockfile XML parser version in CI only; the application uses the native browser parser.

## Acceptance
Run focused Phase 16–25 tests, full build and full suite. Browser-check genuine DOCX and XLSX files from Word, Excel and LibreOffice, multiple worksheets, formulas with/without caches, hidden sheets, tables, Unicode, archive corruption, oversized or password-protected files and macro rejection. Verify mobile performance, clear/discard, account switching, no uploads, selected-section admission and fresh RAG references. Test generated fixtures use genuine ZIP structures with stored and raw-deflate compression, but they do not establish compatibility with every Office producer or live browser acceptance. Production deployment is not authorized or performed.
