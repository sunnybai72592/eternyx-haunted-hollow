# Wave 22 — mediated evidence delivery (review candidate)
Wave 21 PR #747 merged; both CI workflows succeeded. Live staging read-only query confirmed all eight Wave 20 policies, zero Auth users and zero evidence records. No Wave 22 deployment or database change was made.

The Edge gateway handles upload and download. It validates the user JWT with Auth and reads metadata using the caller's JWT, so deployed Wave 20 session and ownership RLS remain mandatory. Only the byte operation uses a server-only Storage credential. Download accepts a registered evidence ID, never a caller-supplied path; it verifies ownership, canonical three-part path, bounded size, and rechecks metadata before returning bytes as a non-cacheable attachment. Upload derives owner, path and size, prohibits upsert, and registers through the caller's RLS and existing audit trigger. Ambiguous registration failures retain potential orphan objects for controlled reconciliation; no privileged delete operation exists. MIME allowlist is not content scanning. No hashes or malware scanning are claimed.
