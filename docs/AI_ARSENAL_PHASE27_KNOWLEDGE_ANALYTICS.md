# AI Arsenal Phase 27 — local knowledge analytics

This workbench processes the current validated local corpus on explicit request. It recognizes literal key: value and key = value lines, normalizes field keys using NFKC, whitespace folding and lowercase, preserves all repeated observations, and records original source names, decoded line numbers and half-open UTF-16 offsets. The evidence matrix counts observations per source. Missing is not zero. At most 200 distinct fields and 2,000 observations are admitted; exceeding either cap rejects the report. Matching lines with values longer than 240 characters or lines longer than 400 characters are excluded and counted.

A standalone signed decimal and supported case-sensitive unit may be converted to a common unit for voltage, current, length, mass, pressure, absolute temperature or percentage. Supported units are explicitly enumerated in the source; scientific notation, ranges, dates, compound measurements and unsupported units are not inferred. Fahrenheit uses the affine absolute-temperature conversion, not temperature differences. Numeric equivalence uses a small floating-point tolerance (relative 1e-9, absolute 1e-12 in canonical units); this is not a metrological or acceptance tolerance. The report distinguishes single-source, literal match, arithmetic converted match, different recorded values and mixed/incompatible fields. Repeated observations remain visible; no preferred value is selected. Matching field labels cannot establish identical assets, locations, test methods, reference electrodes, timestamps or conditions. These are review signals, not compliance determinations or proof of disagreement.

Users can filter the matrix by field name and comparison status, inspect original lines and normalized measurements, copy counts-only reports, or explicitly confirm a selected-field evidence JSON copy. The latter contains source names, original lines and values and must be treated as confidential where applicable. Changing filters clears the export selection; source changes hide and release the prior report. No new runtime dependency, AI call, backend write, upload or persistent storage is introduced.
