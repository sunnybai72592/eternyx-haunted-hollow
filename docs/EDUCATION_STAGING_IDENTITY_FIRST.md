Never commit or upload it. The SQL transaction creates seven labeled synthetic exams, six existing attempts, two grades through the real trusted finalizer and one entirely unused fresh exam. It refuses a duplicate fixture run; no deletes or resets. The read exam expires after 24 hours. Use the full release **journey** mode, not independent rehearsal mode (the baseline final-A review is already finalized, and journey substitutes the actual new attempt).
