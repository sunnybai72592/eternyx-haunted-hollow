# Education — Question Bank Studio editing quality

**Status: real local editor improvements only; NOT DEPLOYED.** This PR does not grant instructor access, publish exams, enable previously staged backend services, deploy SQL or modify a hosted Supabase project.

## What changes in the working instructor editor

The existing Education Question Bank Studio already supports real validated MCQ, True/False, written questions, learner-safe previews, private instructor drafts and portable JSON files. This milestone improves daily authoring for larger banks.

**Undo and redo:** up to **30 actual in-memory edit snapshots** restore and reapply question-bank changes, including question text, marks, options, correct-answer selection, order and bank metadata. No browser storage or server backup is silently created. An edit following undo discards its old redo branch. An imported JSON or fetched instructor draft starts a new history with no earlier answer-key snapshots. New Bank resets the history as well. Editing a partially completed field does not discard the keystroke; validation remains the gate for export or server save.

**Duplicate question safely:** the selected question can be copied immediately after its original. A copied MCQ or True/False item retains its human-entered text, points and intended correct choice but receives unique new question **and** option identifiers generated by the browser. Written questions copy no hidden options. The existing 100-question limit is enforced. The editor requires an internally valid local draft before making a duplicate and asks the instructor to check its answer key.

**Navigate large banks:** search question wording without sending anything to an API, filter locally by MCQ/True-False/Written, preserve the original question number, show exact filtered counts, and clear filters to return to the full list. Filtering never removes questions from the bank or changes export ordering.

**Find issues quickly:** the existing real export validator already identifies which question needs work. A **Jump to first question issue** action now opens that exact item, clears any hiding filters, and switches to the editor. The studio also highlights repeated question wording after normalizing case and whitespace. Duplicate wording is an editorial warning rather than a fabricated grading condition or a forced publication rejection.

**Protect instructor answer keys:** changing signed-in accounts now resets **every** local or server-loaded draft, not only private server drafts, and clears every undo/redo snapshot. The privacy reset uses a pre-paint React effect to avoid briefly rendering the previous user's answer key. Import and server-load actions also reset the edit history, so undo cannot recover another imported bank.

## Boundaries and tests

- The existing trusted instructor permission checks, publication request RPC, separate admin decision and published/enrolled learner workflow remain unchanged. No new backend API or service-role key.
- Local answer keys are never stored in localStorage, IndexedDB, sessionStorage, analytics or browser background sync. Export and private draft save still require explicit instructor action.
- **39 Node regression checks** exercise real pure helper transformations, duplicate-ID rejection, safe copying of answer flags, question limits, search/type filtering, duplicate warning, validation navigation, 30-step undo/redo, snapshot reset and actual editor source wiring.
- Standard application tests, build, GitGuardian and desktop/mobile browser acceptance must pass before merging.
- This is source-controlled frontend behavior, not proof of hosted staging deployment, and **not production certification**. Production rollouts still require separately approved SQL/Auth/RLS testing and release authorization.

Known tradeoff: only the 30 most recent local edit snapshots are retained; closing the tab still loses unexported edits. This is intentional to avoid persisting private correct-answer keys on a shared device. Export a local draft JSON or save a new approved private server draft when appropriate.
