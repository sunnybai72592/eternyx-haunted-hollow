# AI Arsenal Phase 20 — local lexical knowledge engine

Explicitly build an in-memory inverted index over the currently loaded TXT/Markdown/CSV/JSON/LOG decoded text. The existing corpus admission limits (eight sources, 100,000 UTF-16 characters per file, 400,000 total) remain. Extract contiguous nonoverlapping passages of at most 1,000 UTF-16 units, preferring a line or whitespace break within the final 300 units. Preserve original line endings, source offsets and exact source text; avoid cutting valid surrogate pairs or CRLF. Punctuation-only passages are not indexed. Long unbroken words may split at hard boundaries. This is passage extraction, not binary PDF/Office parsing or OCR.

Index normalized NFKC lowercase Unicode words and their per-passage frequencies. Search with up to eight distinct terms and 120 query characters, all/any matching, and optional source filter. Rank with BM25 (k1=1.2, b=0.75), using global indexed passage document frequency and average token count; ties use original index order. Scores are relative lexical ranking, not probability or confidence. Return the actual match count and at most 30 results. Each result contains exact source text, source label, one-based physical line range and zero-based half-open decoded UTF-16 offsets. Copying a passage includes source text and may disclose sensitive data; no automatic sharing.

The index is built explicitly; discard releases its component references, not secure memory erasure. Source mutation, restoration, undo or clearing invalidates the index and results. A source-array identity guard also hides stale indexes. Independent search controls clear their results on changes. No vector embeddings, AI training, generated answers, runtime dependency, remote request, persistence or backend changes.
